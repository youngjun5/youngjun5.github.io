# 🎬 케어스크립트 (CARE SCRIPT)
현장 스크립터 1인 멀티용 앱. 아이패드 세로 화면 기준.

## 켜는 법
`실행하기.command` 더블클릭 → 터미널이 열리고 서버가 켜지면서 브라우저가 자동으로 뜹니다.
끌 때는 그 터미널 창에서 `Control + C`.

## 어디서 쓰나
- **케어센터(웹)**: https://youngjun5.github.io/carescript/ — 인터넷만 되면 맥·아이패드·폰 어디서든 같은 기록을 실시간으로 봅니다. 아이패드 사파리에서 *공유 → 홈 화면에 추가* 하면 앱 아이콘이 생깁니다.
- **현장 LAN 모드**: 인터넷이 없는 현장에서는 맥 1대에서 `실행하기.command` 를 켜면 같은 와이파이끼리 공유됩니다. 앱이 켜질 때 자동으로 감지해서 그쪽으로 붙습니다.
- ⚙︎ 설정에서 언제든 수동으로 바꾸거나 "공유 끄기"(이 기기에만 저장)를 할 수 있습니다.

## 앱을 고쳤을 때
바탕화면 `케어스크립트` 폴더에서 고친 뒤 **`케어센터에배포.command`** 를 더블클릭하면 케어센터에 올라갑니다. (1~2분 뒤 반영)

## 맥끼리 / 아이패드 공유 (현장 LAN)
서버를 켠 맥의 터미널에 이런 주소가 뜹니다.

```
다른 맥/아이패드: http://192.168.0.x:7788/
                  http://맥이름.local:7788/
```

같은 와이파이(현장 공유기, 아이폰 핫스팟도 가능)에 연결된 다른 맥·아이패드 사파리에서
그 주소로 접속하면 **실시간으로 같은 기록을 봅니다.** (인터넷 불필요)
- 앱 안에서 접속했다면 자동 연결 (우측 상단 점이 초록색).
- 파일로 직접 연 경우엔 ⚙︎ 설정 → 서버 주소 입력 → 연결.
- 충돌은 "나중에 고친 쪽이 이김" 방식으로 자동 병합됩니다.

## 아이패드에 아이콘으로 설치
사파리로 접속 → 공유 버튼 → **홈 화면에 추가**. 전체화면 앱처럼 실행됩니다.

## 구성
- **홈**: 폴더 → 프로젝트(작품). ＋ 버튼으로 생성. 우상단 ◐ 로 다크모드 켜고 끄기.
- **프로젝트**: 용지 목록. 상단 `분류`에서 **날짜·씬·컷·특이사항 멀티셀렉트 필터** + 대사 내용 검색.
- **스크립트 용지**: 현장에서 쓰는 종이 양식 그대로입니다.

```
                                        PAGE NO.
 < 작품명 > 스크립트 용지 / SCRIP PAPER
                                   감독 /      스크립터 /
 20  년  월  일   촬영시작:    끝:    촬영장소:
┌──────┬──────┬──────────────┬──────────────┐
│ S#   │ C#   │ 컷 설명       │ 날씨 / 광선   │
│      │      │              │ 기온 · 조명   │
├──────┴──┬───┴──┬──────┬────┴───┬──────────┤
│ Film    │ Lens │Filter│  Exp   │  Roll    │
├─────────┴──┬───┴──────┴─┬──────┴──────────┤
│ 연결        │ 카메라 위치  │ 사운드           │
│ Continuity │ Tracking   │ 동시녹음         │
│ + 특이사항  │ Fix / Pan  │                 │
├────────────┴────────────┴─────────────────┤
│ 지문과 대사 / Action & Dialogue  (전체 폭)   │
│  대본 · 음성인식 · 어미검사                   │
└───────────────────────────────────────────┘
```

- **칩으로 고르는 항목(날씨·조명·Film·Lens·Filter·Exp·사운드·특이사항)은 비어 있습니다.**
  `＋` 를 눌러 현장에서 쓰는 이름을 직접 등록하세요. 한 번 만들면 모든 용지에서 계속 씁니다.
- 지울 때는 **항목 오른쪽 위의 빨간 `－`** 를 누르세요. 확인 후 삭제되고,
  **그 항목을 쓰고 있던 용지가 몇 장인지 먼저 알려줍니다.**
- Tracking / Fix / Pan 은 용지에 인쇄된 고정 항목이라 그대로 들어있습니다.
- **지문과 대사 칸은 페이지 전체 폭**을 씁니다. 대사가 길어도 한눈에 들어옵니다.
- **어미검사 옆 씬 목록**에서 필요한 씬을 고르면 그 씬으로 바로 갑니다.
- 대본은 **씬 하나가 한 페이지**입니다. 씬 표시(`S#`)가 없는 대본이면
  한 쪽에 대사 20개씩 나누고, 페이저 아래 `＋ / －` 로 쪽당 줄 수를 조절합니다.
  칸 아래에 `‹ 이전 / 씬 목록 / N쪽 중 M / 다음 ›` 이 나오고, 전체 몇 쪽인지 함께 보입니다.
- 음성인식이 **다른 쪽 대사를 잡으면 그 쪽으로 자동으로 넘어갑니다.**
- **지문은 전부 대사 단락 안에 들어갑니다.** 회색으로 따로 떨어뜨리지 않고
  같은 크기·같은 색으로 대사와 이어져 읽힙니다 (기울임체로만 구분).
  따로 떼려면 지문 옆 `떼기`, 다시 넣으려면 `합치기`.
- **씬 제목은 크게 표시**되어 한눈에 구분됩니다.
- 화면은 **검정과 흰색만** 씁니다. 빨간색은 두 곳에만 씁니다 —
  **이미 친 대사의 빨간 취소선**, **어미 반복 글자 위의 빨간 점**.

## 대본 넣기
`📄 파일 불러오기` 또는 **화면에 파일을 그냥 끌어다 놓으면** 됩니다.

| 형식 | 지원 |
|---|---|
| PDF | ✅ (한글 PDF 포함. 글자층 없는 스캔본은 자동으로 글자 인식) |
| 워드 | ✅ `.docx` (구형 `.doc`은 docx나 PDF로 저장 후) |
| 한글 | ✅ `.hwpx` — **구형 `.hwp`는 안 됨.** 한글에서 *다른 이름으로 저장 → HWPX 또는 PDF* |
| 페이지스 | ✅ `.pages` (문서 안의 미리보기를 사용. 안 되면 PDF로 내보내기) |
| 이미지 | ✅ `.png .jpg .heic` 등 — 사진 속 글자를 읽습니다 (한국어+영어) |
| 텍스트 | ✅ `.txt .md .rtf .fdx`(파이널드래프트) `.fountain` |

- `📋 붙여넣기` — "이름: 대사" 또는 시나리오 형식(이름 줄 + 대사 줄) 자동 인식
- 불러오기 전에 **"이렇게 읽었어요"** 확인 화면이 떠서 대사/지문/인물 수를 미리 봅니다.
- 인물이 잘못 잡혔으면 불러온 뒤 대사 왼쪽 **이름을 눌러** 고치면 됩니다.

> ⚠️ PDF·워드·한글·이미지를 여는 도구는 인터넷에서 내려받습니다. **대본은 현장 나가기 전에 미리 불러와 두세요.** 한 번 불러온 대본은 인터넷 없이도 그대로 씁니다.

## 음성인식 (친 대사 자동 밑줄)
1. 하단 🎙 버튼 ON (첫 실행 시 마이크 권한 허용)
2. 배우가 대사를 치면 **일치하는 줄에 자동으로 빨간 취소선** → "이건 이미 친 대사"
3. 대본과 다르게 쳤으면 **대본불일치**로 표시 + 실제로 친 말이 그대로 남음
   → `대본에 반영`(특이사항에 '대본 수정' 자동 추가) 또는 `무시`
4. 정확도 임계값 슬라이더로 민감도 조절 (현장 소음 심하면 낮추기)
5. `○` 버튼으로 수동 표시, `후` 버튼으로 **후시 필요** 표시 → 사운드 항목에 자동 반영

## 어미 반복 검사 (ON/OFF)
같은 문장 안에서 **똑같은 어미가 반복되면 그 글자 위에 빨간 점**이 찍힙니다.

> 어제 내가 작업을 해<sup>●</sup>서, 오늘 일어나<sup>●</sup>서 피곤해 → `'서' 어미 2회 반복 (연속)`

- 어미 종류는 상관없이 반복 자체를 잡습니다 (서/고/며/면/니/데… 연결어미 + 종결어미 연속).
- `고치기 도움` 버튼 → 대체 표현 제안.
- `어미검사 ON/OFF` 버튼으로 껐다 켤 수 있습니다. (사전 점검용)

## 내보내기 / 백업
- 프로젝트 `⋯` → **CSV 내보내기** (엑셀에서 바로 열림. 대사별 밑줄·후시·불일치·어미경고까지 전부 컬럼으로)
- ⚙︎ 설정 → **전체 백업(JSON)** / 복원

## 새 버전이 안 보일 때
배포하면 파일 주소에 버전이 붙어 자동으로 최신을 받아옵니다.
그래도 옛 화면이 보이면 ⚙︎ 설정 → **최신 버전으로 다시 불러오기**.
설정창 아래에 현재 버전(예: 260917.1731)이 표시됩니다.
